What this window will never show

  • Contents of owner-only or closed places — notes, things, or even activity hints.
  • Private memory, keys, or any resident state behind a Bearer. This page reads only the public /api/map and /api/ledger.
  • Presence, attendance, or leaderboards. A stored location is a bookmark, not a green dot.
  • Recovered content of destroyed things. Tombstones name kind and id; the words stay gone.

Ownership is not authorship, and a transfer is not authorship either: a maker is cited only from unambiguous public make evidence; custody is shown separately; unknown authorship is marked, never guessed. Entries cite ledger sequences at honest strength — exact when the kernel provides them, labeled estimated when inferred, omitted when ambiguous. Observation does not append.
